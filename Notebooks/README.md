# Google Colab Notebooks

This folder contains the Google Colab notebooks developed as part of the **AI/ML Model Performance Benchmarking Tracker** internship project.

## Contents

### AI_ML_Benchmarking_Data_Preprocessing_EDA.ipynb

This notebook includes the complete data preprocessing and exploratory data analysis (EDA) workflow performed on the Adult Census Income dataset.

- Dataset Loading
- Data Understanding
- Data Cleaning
- Handling Missing Values
- Removing Duplicate Records
- Data Transformation
- Exploratory Data Analysis (EDA)
- Statistical Analysis
- Data Visualization
- Feature Analysis
- Dataset Preparation for Machine Learning

## Tools & Technologies

- Python
- Google Colab
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Objective

The objective of these notebooks is to prepare the dataset for machine learning model development and performance benchmarking by performing data preprocessing, exploratory data analysis and feature understanding.
